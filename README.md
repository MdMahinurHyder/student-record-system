# Student JSON Record System

A beginner Python project created while learning Python Intermediate concepts.

## Features

- Register a new student
- Enter multiple subjects and marks
- Store student records in JSON
- Retrieve existing student information
- Handle invalid numerical input
- Handle missing JSON files

## Python Concepts Practiced

- JSON
- File handling
- Exception handling
- List comprehension
- Dictionary comprehension
- `zip()`
- Loops
- User input

## How to Run

```bash
python student_record.py
